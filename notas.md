Notas de aprendizaje — Laboratorio N.° 01


En este laboratorio aprendí sobre la importancia de elegir correctamente los lenguajes, frameworks y bases de datos según las necesidades de cada proyecto. También aprendí a configurar herramientas como Node.js, Java y VS Code, además de utilizar Git y GitHub para crear repositorios, realizar commits, trabajar con ramas y fusionar cambios mediante un Pull Request. Todo esto me ayudó a comprender mejor el flujo básico de trabajo de un desarrollador Full Stack.
